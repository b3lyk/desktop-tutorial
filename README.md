# MY LIFE v1.0

Первая PWA-версия личного трекера финансов, задач и достижений.

## Что работает
- Доходы и расходы в рублях, категории, комментарии и даты.
- Баланс за всё время и итоги за месяц/год.
- Задачи со сроком, приоритетом и отметкой выполнения.
- Личные достижения.
- Аналитика и экспорт резервной копии JSON.
- Адаптивный тёмный интерфейс, установка как PWA и офлайн-кеширование после первого посещения.

## Как запустить
Откройте `index.html` в браузере для локальной проверки. Для установки на iPhone как PWA сайт нужно разместить по HTTPS (например, на GitHub Pages или другом статическом хостинге).

На iPhone: откройте HTTPS-адрес в Safari → «Поделиться» → «На экран Домой».

## Важно
Данные сейчас хранятся локально в браузере через localStorage на конкретном устройстве/браузере. Они не синхронизируются между устройствами и могут потеряться при очистке данных Safari. Регулярно используйте «Экспортировать резервную копию». Для надёжной синхронизации понадобится облачная база и авторизация.

Автоматическое подключение банков не включено: оно требует совместимого API/провайдера и отдельной настройки безопасности. Импорт выписок CSV можно добавить следующим этапом.

## Дальнейшая дорожная карта
1. Разместить PWA на HTTPS и проверить установку на iPhone.
2. Добавить импорт банковских CSV-выписок и правила категорий.
3. Добавить облачную синхронизацию и вход пользователя.
4. Подготовить нативную iOS-оболочку/сборку через облачный CI, без необходимости иметь Mac локально.
